# OKX FastBand 선물 자동매매 봇 v2.0.0

OKX USDT 무기한 선물 5분봉 볼린저 밴드 오버슈팅 역추세 페이드(Fade) 전략 봇입니다.  
v2.0.0에서는 실전 매매 안정성과 수익성 극대화를 위한 **3대 핵심 전략 개선안(손익비 개선, BTC 서킷 브레이커, ATR 동적 TP/SL)**이 적용되었습니다.

---

## 📌 v2.0.0 핵심 개선 사항

### 1. 손익비(Risk/Reward) 불균형 개선 및 분할 익절 구조
- **기존 문제점**: `TP 1.2% / SL 1.5%` (손익비 약 0.8:1) 고정 구조로 인해, 수수료와 슬리피지를 감안하면 최소 60~62% 이상의 승률이 강제됨.
- **v2 개선 내용**:
  - **1차 분할 익절**: +1.0% 도달 시 포지션의 50%를 시장가로 즉시 분할 익절하여 순익을 조기 확정.
  - **본절 스탑(Break-Even Stop)**: 1차 익절 직후 잔여 50% 물량의 스탑로스를 진입가(+0.1% 수수료 보전 버퍼)로 자동 상향 이동.
  - **트레일링 익절(Trailing Stop)**: 남은 50% 물량은 최고 수익률 1.2% 이상 도달 시 고점 대비 -0.4% 되돌림 시 자동 익절 처리하여 추가 추세 수익 확보.

### 2. 비트코인(BTC) 연동 필터 (시장 서킷 브레이커)
- **기존 문제점**: 비트코인이 순간 급락할 때 여러 알트코인이 동시에 하단 밴드를 찢으며 대량 롱 진입 후 연쇄 손절되는 시스템적 위험 존재.
- **v2 개선 내용**:
  - `BTC-USDT-SWAP` 5분봉의 등락폭이 ±1.0% 이상이거나 고저 진폭이 급등할 경우, 모든 알트코인의 신규 역추세 진입을 3분간 일시 정지(`BTC_COOLDOWN_SEC = 180`).
  - 텔레그램으로 서킷 브레이커 발동 및 해제 상황 즉시 알림.

### 3. 고정 비율 대신 ATR 기반 동적 TP / SL
- **기존 문제점**: 코인별 변동성 차이를 무시한 고정 1.2% TP / 1.5% SL로 인해, 변동성이 큰 알트코인에서 정상적인 숨고르기 파동에도 휩쏘(속임수 무빙)로 손절되는 현상 발생.
- **v2 개선 내용**:
  - 해당 심볼의 최근 14개 5분봉 ATR(Average True Range)을 실시간 산출하여 목표가와 손절가를 동적 계산.
  - `TP = ATR * 1.4` (0.8% ~ 2.5% 범위 클램핑)
  - `SL = ATR * 1.8` (1.0% ~ 3.0% 범위 클램핑)
  - 변동성이 큰 종목은 넉넉한 슬롯 확보로 휩쏘를 방어하고, 변동성이 작은 종목은 타이트하게 익절.

## 🛠 모듈 구성 및 변경 내역

| 파일명 | 역할 및 v2 변경점 |
|---|---|
| `state.py` | 전역 상태 및 파라미터 관리. v2 설정값(`APP_VERSION="2.0.0"`, `PARTIAL_TP_*`, `BTC_CIRCUIT_*`, `ATR_*`) 추가 |
| `okx_api.py` | OKX v5 REST API 통신. 50% 분할 익절을 위한 `place_market_order` 함수 추가 |
| `entry.py` | 진입/청산 로직. `calc_atr_pct`, `_is_btc_circuit_breaker_active`, `_execute_partial_tp_and_bep` 추가 및 OCO 동적 적용 |
| `main.py` | 웹소켓 틱 처리 및 실시간 제어. BTC 심볼 상시 구독 보장, 텔레그램 상태 출력 및 v2 제어 명령어 연동 |
| `server.py` | 텔레그램 명령 처리 서버. v2 제어 명령어(`btc서킷`, `atr`, `분할익절`, `트레일`) 유효성 등록 |
| `config.py` | 존(Zone) 및 기본 타임프레임 상수 설정 |

## 📱 텔레그램 제어 명령어 (v2 추가)

기존 명령어 외에 아래의 v2 전용 제어 명령어를 텔레그램 봇으로 전송하여 실시간 변경할 수 있습니다:

- `상태`: FastBand v2.0.0 전체 설정 및 활성 포지션, PnL 확인
- `btc서킷켜` / `btc서킷꺼`: BTC 서킷 브레이커 ON / OFF
- `atr켜` / `atr꺼`: ATR 동적 TP/SL ON / OFF (OFF 시 고정 TP/SL 모드)
- `분할익절켜` / `분할익절꺼`: 1차 50% 분할 익절 ON / OFF
- `트레일켜` / `트레일꺼`: 잔여 50% 트레일링 익절 ON / OFF
